# Data Cleaning with Python

## Overview

This repository showcases practical data cleaning projects developed using **Python** and **Pandas**. Each project focuses on transforming raw, messy datasets into clean, structured, and analysis-ready data using industry-standard preprocessing techniques.

The projects demonstrate the complete data preparation workflow, including data inspection, cleaning, transformation, validation, feature engineering, and preparing datasets for downstream analysis.

# Project Details

## 1. Employee Dataset Cleaning Project

### Objective

Clean a messy employee dataset by improving data quality and preparing it for analysis.

### Dataset

Messy Employee Dataset

### Key Tasks Performed

- Explored dataset structure
- Inspected missing values
- Removed duplicate records
- Corrected data types
- Standardized categorical values
- Cleaned text fields
- Split combined columns
- Validated cleaned data
- Exported analysis-ready dataset

### Files

- `Notebook_employee_dataset_cleaning_project.ipynb`
- `Messy_employee_dataset.csv`
- `Cleaned_employee_dataset.csv`

## 2. Movie Dataset Cleaning Project

### Objective

Prepare an IMDb movie dataset containing **449 movies** for exploratory data analysis by cleaning missing values, standardizing text fields, engineering new features, and validating data quality.

### Dataset

IMDb Movies Dataset (449 Movies)

### Key Tasks Performed

- Explored dataset structure
- Removed unnecessary columns
- Handled missing values
- Standardized text fields
- Corrected inconsistent categorical values
- Created analytical features
- Detected potential outliers
- Validated cleaned dataset
- Exported analysis-ready dataset

### Files

- `IMDb Movies Dataset (449 Movies) notebook.ipynb`
- `movie_dataset (449 movies).csv`
- `cleaned_movie_dataset.csv`
